# CodePet

[English](README.md) | **한국어**

[다운로드](https://github.com/nokryong/CodePet/releases/latest) · [릴리즈 노트](CHANGELOG.md) · [AppImage 카탈로그](https://appimage.github.io/CodePet/)

Codex, Antigravity(AGY), Claude Code, Grok을 위한 데스크톱 펫입니다. 에이전트의 작업 상태와 남은 한도를 확인하고, 계정을 전환하거나 단체 채팅방에서 함께 대화할 수 있습니다.

Windows, Linux, macOS를 지원합니다.

## 시작하기

운영체제에 맞는 실행 파일을 내려받으세요. Windows는 `.exe`, Linux는 `.AppImage`, macOS는 Intel·Apple Silicon 공용 `.dmg`를 사용합니다.

펫이나 트레이 아이콘을 우클릭하면 설정, 계정 관리, **에이전트 채팅방…**을 열 수 있습니다.

Windows 포터블 버전은 설정의 업데이트 버튼을 누르면 새 버전을 다운로드하고 적용한 뒤 자동으로 재실행합니다. Linux·macOS에서는 같은 버튼으로 새 버전을 다운로드합니다.

## 주요 기능

- **작업 상태 표시:** 지원하는 CLI와 데스크톱 앱의 작업, 도구 실행, 대기, 완료, 중단을 말풍선과 애니메이션으로 보여줍니다. 말풍선은 전체 내용·상태만·끄기 중 선택합니다.
- **남은 한도:** 현재 계정의 조회 가능한 잔여 한도와 초기화 시각을 확인합니다. Windows에서는 기본 모니터의 가로 작업표시줄 알림 영역 옆에도 표시합니다. 표시줄이나 트레이 아이콘을 클릭하면 상세 정보가 열립니다. 1분마다 갱신하며, 조회 불가나 이전 값은 구분해서 표시합니다.
- **계정 관리:** 펫 메뉴나 트레이에서 Codex·AGY·Claude·Grok 계정을 추가·전환하고, 설정에서 저장 계정을 삭제합니다.
- **화면 설정:** 펫, 말풍선 색상, 시스템 글꼴과 글자 크기를 고릅니다. 글자 크기는 채팅 본문과 입력창에도 적용됩니다. 이동 설정, 위치와 크기는 재실행 후에도 유지됩니다.
- **회사 모드:** 설정 → 일반 및 모양에서 켜면 펫과 채팅 캐릭터·이모티콘을 숨깁니다. 채팅방은 트레이에서 열 수 있습니다.
- **자동 실행:** 우클릭 메뉴에서 로그인 시 자동 실행을 설정합니다.

현재 지원하는 Grok CLI는 계정 한도 조회를 제공하지 않습니다.

## 에이전트 채팅방

사용할 CLI(`codex`, `claude`, `agy`, `grok`)를 설치하고 로그인하세요. 에이전트가 표시되지 않으면 사이드바의 **환경 진단** 또는 **CLI 다시 탐지**를 사용합니다.

**Antigravity IDE와 `agy` CLI는 별개입니다.** IDE가 설치되어 있어도 채팅에는 CLI가 필요합니다.

- **세션:** 대화를 만들고 이름을 바꾸거나 전환합니다. 메시지 내용 검색과 전체 대화의 Markdown 내보내기를 지원합니다. 삭제한 세션은 휴지통에 30일간 보관합니다.
- **대화 기록:** 최근 메시지부터 최대 50개씩 표시합니다. 새 메시지는 아래에 쌓이고, 위로 스크롤하면 읽던 위치를 유지하며 이전 대화를 불러옵니다.
- **작업 기록 공유:** 에이전트가 필요할 때 같은 대화방의 실행 명령·도구 입력·결과·오류를 조회합니다. 실행 중인 기록도 확인할 수 있으며, 용량에 따른 생략이나 자동 만료 없이 압축 저장하고 나눠 읽습니다. 기록의 상세 범위는 CLI에 따라 다릅니다.
- **멘션:** 멘션 없이 보내거나 `@모두`, `@all`을 쓰면 참여 중인 에이전트 모두가 같은 메시지를 동시에 받아 작업합니다. 답변은 완료 순서대로 표시됩니다. `@codex`, `@claude`, `@agy`, `@grok`으로 대상을 지정할 수 있습니다. 에이전트끼리도 여러 명에게 동시에 후속 작업을 전달하며, 같은 참가자의 작업만 순서를 기다립니다. 호출 횟수 제한은 없습니다.
- **발언 제어:** 작업 중인 참가자와 대기 순서를 확인하고, 개별 턴 취소·끼어들기·응답 중지를 할 수 있습니다.
- **복수 계정:** 설정에 저장한 Codex·Claude·Grok 계정을 채팅방의 **계정 추가**로 참여시킵니다. 사용 가능한 계정만 `메일주소(에이전트)(요금제)`로 표시합니다. 참가자마다 멘션·모델·추론·작업 기록을 구분하며, 서비스별 CLI 하나로 실행합니다. 기본 참가자는 현재 전역 계정을 사용하므로 중복 참여를 원치 않으면 참여를 끄세요.
- **토론:** 턴 수 제한 없이 참가자들이 차례로 답하며 합의·결론에 도달하면 종료합니다. 중지·끼어들기로 직접 끝낼 수 있습니다.
- **에이전트 설정:** 참가자 칩에서 참여 여부, 모델, 추론, 도구 자동 승인을 선택합니다. 표시 이름과 `@호출명`도 대화방별로 변경할 수 있으며, 기존 호출명도 계속 사용할 수 있습니다. 모델과 추론 선택지는 설치된 CLI에서 조회하며, 모델 목록 조회에 실패하면 실행할 수 없습니다. 별도로 지정하지 않은 설정은 CLI 설정을 따릅니다.
- **메시지:** 실시간 응답, 인용 답장, 복사 버튼이 있는 코드 블록, 서식·링크와 캐릭터 이모티콘을 지원합니다.

### 워크스페이스와 권한

세션마다 작업 폴더와 권한 모드를 선택합니다.

| 모드 | 용도 |
|---|---|
| 대화만 | 프로젝트 폴더를 지정하지 않는 기본 대화 모드 |
| 워크스페이스 읽기 | 프로젝트 파일 읽기·검색 |
| 워크스페이스 쓰기 | 프로젝트 수정 허용. 추가 도구 권한은 승인이 필요할 수 있음 |

Grok의 워크스페이스 접근에는 Windows·Linux의 로컬 Docker Linux 백엔드가 필요합니다. 쓰기 모드에서는 격리된 복제본을 수정하며, 변경 내용을 검토하고 **전체 적용**을 눌러야 원본에 반영됩니다. Linux에서는 현재 사용자가 `sudo` 없이 `docker info`를 실행할 수 있어야 합니다.

도구 자동 승인은 쓰기 모드에서 에이전트별로 켤 수 있습니다. 신뢰하는 폴더에서만 사용하세요.

### 첨부 파일

**＋** 버튼, 드래그 앤 드롭, 스크린샷 붙여넣기를 지원합니다. 한도는 **파일당 20MiB**, **세션당 200MiB**입니다.

첨부는 세션 폴더에 복사됩니다. 이미지는 Codex와 읽기 권한이 있는 Claude에 전달할 수 있습니다. AGY·Grok의 이미지 전달은 지원하지 않으며, 전달되지 않은 첨부는 답변에 표시합니다. 실행 파일은 첨부할 수 없습니다.

## Live 음성 대화

펫이나 트레이 아이콘을 우클릭하고 **Live 음성 대화…**를 선택합니다. 설치된 Codex CLI에 ChatGPT 계정으로 로그인한 뒤 Live에서 시작 버튼을 누르세요. 마이크 버튼으로 음소거하고, 통화 중 메시지를 입력하거나 종료 버튼으로 통화를 끝낼 수 있습니다. 창을 닫으면 마이크 사용도 종료됩니다.

- **대화 목록:** 왼쪽 사이드바에서 지난 대화를 선택하면 저장된 내용을 확인하고 이어갈 수 있습니다. **새 대화**로 별도 대화를 시작합니다. 좁은 창에서는 메뉴 버튼으로 사이드바를 엽니다.
- **프로젝트:** 대화마다 작업 폴더를 따로 저장합니다. 새 대화의 기본값은 Windows의 `C:\Users\사용자이름` 같은 사용자 홈 폴더입니다. 대화 위의 프로젝트 경로를 누르면 설정에서 다른 폴더를 선택할 수 있습니다.
- **권한:** **승인 요청**은 신뢰되지 않은 명령과 추가 접근에 승인을 요청합니다. **나 대신 승인**은 일반적인 작업 폴더 작업을 허용하고 추가 접근에 승인을 요청합니다. **전체 권한**은 파일과 네트워크 접근 제한 없이 실행합니다. 승인 요청은 Live 안에서 처리하며, 권한을 바꾸면 통화를 다시 연결합니다.
- **삭제:** 대화 옆의 **×**를 누르고 확인하면 저장된 메시지와 해당 대화의 전용 Codex 기록을 삭제합니다. 진행 중인 대화를 삭제하면 통화도 종료됩니다.

대화 모델과 음성 목록은 로그인한 Codex에서 불러옵니다. 통화를 종료한 뒤 음성 설정에서 새로고침할 수 있습니다. 음성 모델은 서버 기본값을 사용하며, 연결에서 이름을 제공할 때만 표시합니다. 별도 언어 선택 없이 사용자가 말하는 언어를 따릅니다.

Live는 설정·에이전트 채팅방과 같은 테마를 사용합니다. 창 크기를 조절할 수 있고, 회사 모드에서는 캐릭터 대신 움직이는 구체를 표시합니다.

## 계정 전환

| 서비스 | 동작 |
|---|---|
| Codex | 기본으로 켜진 로컬 프록시를 통해 재시작 없이 전환합니다. 최초 활성화 시 이미 열린 Codex를 한 번 재시작해야 할 수 있습니다. |
| AGY | 저장 계정으로 전환한 뒤 Antigravity를 재시작합니다. |
| Claude | 새 세션부터 선택한 계정을 사용하며 기존 세션은 유지합니다. |
| Grok | 다음 API 호출부터 선택한 OAuth 계정을 사용합니다. API 키는 계정 프로필로 저장하지 않습니다. |

현재 계정은 다른 계정으로 전환한 뒤 삭제할 수 있습니다. CodePet 강제 종료 후 Codex가 연결되지 않으면 CodePet을 다시 실행해 프록시 설정을 복구하세요.

Linux의 AGY 계정 저장에는 Secret Service와 `secret-tool`이 필요합니다. Debian·Ubuntu에서는 `libsecret-tools` 패키지를 설치합니다.

## 조작법

| 동작 | 반응 |
|---|---|
| 펫 클릭 | 인사 |
| 더블클릭 | 설정의 한도 화면 열기 |
| 드래그 | 펫 이동 |
| 펫·트레이 아이콘 우클릭 | 메뉴 열기 |
| 작업표시줄 한도 표시·트레이 아이콘 클릭 | 남은 한도 보기 |
| 지원되는 Codex 완료·대기 말풍선 클릭 | 해당 대화 열기 |

**숨기기**는 펫만 감추고 트레이에서 실행을 유지합니다. 앱을 끝내려면 **완전 종료**를 선택하세요.

## 펫 바꾸기

우클릭 메뉴의 **펫 바꾸기**에서 선택합니다. 내장 펫과 `~/.codex/pets`에 설치한 펫을 사용할 수 있습니다.

커스텀 펫은 실행 파일 옆 `pet/` 폴더에 `spritesheet.webp`를 넣으세요. 셀 크기는 192×208, 가로는 8열입니다.

- **v1:** 1536×1872, 9행.
- **v2:** 1536×2288, 11행. 기본 애니메이션은 0~8행을 사용합니다.

## 데이터와 개인정보

에이전트 채팅방의 대화, 첨부 사본, 작업 기록은 `~/.code-pet`에 저장됩니다. 환경 변수 `CODE_PET_HOME`으로 위치를 바꿀 수 있습니다. 앱을 삭제해도 이 폴더는 남습니다. 대화방을 삭제하면 해당 작업 기록도 삭제됩니다.

채팅 저장소는 하드 링크를 지원하는 로컬 파일시스템의 폴더를 사용하세요. 네트워크·공유 폴더는 지원하지 않습니다. 잠금 복구에 로컬 프로세스 ID와 호스트 이름을 사용하므로 이름이 같은 기기나 별도의 PID 공간을 확실히 구분할 수 없습니다. 다른 호스트 또는 소유 호스트를 알 수 없는 잠금은 그대로 유지합니다. 복구 전에 실행 중인 writer가 없는지 확인하고, 다른 인스턴스가 사용 중인 잠금을 삭제하지 마세요.

에이전트 채팅방의 각 참가자는 앱 재시작 후에도 자신의 CLI 세션을 이어 씁니다. 계정·작업 폴더·권한·모델·추론 설정을 바꾸면 새 세션을 사용합니다. 저장 계정 참가자는 해당 계정 프로필을 사용하며, 에이전트 채팅방을 삭제해도 CLI 자체 기록은 삭제되지 않습니다.

Live의 완료된 음성 자막, 입력한 메시지와 전용 Codex 대화 기록은 `~/.codepet/live` 아래에 계정별로 구분해 저장합니다. 앱을 다시 열어도 Live에서 저장된 대화를 선택해 이어갈 수 있습니다. 이전 음성 대화는 자막이 기록되지 않아 내용이 없을 수 있습니다. Live 대화를 삭제하면 로컬 메시지 내용과 해당 전용 Codex 기록을 삭제합니다.

CLI 자격 증명을 채팅 저장소에 복사하지 않으며, 작업 기록에서 알려진 자격 증명 패턴을 가립니다. 저장 계정 프로필은 별도 경로인 `~/.codepet/*-switch`에 보관합니다.

대화 문맥, 지원되는 첨부, 요청한 작업 기록 발췌는 선택한 에이전트 CLI를 통해 해당 서비스에서 처리합니다. AGY가 응답하는 동안에는 운영체제의 프로세스 목록에 프롬프트가 일시적으로 보일 수 있습니다.

## 소스에서 실행

```bash
npm install
npm start
npm test
```

채팅창을 바로 열려면 `npx electron . --chat`, CLI 설치 상태를 확인하려면 `node bin/code-pet.js doctor`를 실행합니다.

`npm run dist`로 현재 운영체제용 패키지를 만들면 `artifacts/`에 배포 파일만 추가되고 임시 빌드 파일은 정리됩니다. 빌드 전에는 CodePet을 종료하세요. 릴리스 워크플로는 Windows·Linux·macOS 패키지와 체크섬을 생성합니다.

Linux에서 FUSE 마운트를 사용할 수 없으면 AppImage에 `--appimage-extract-and-run` 옵션을 붙여 실행하세요. 배포 AppImage에는 AppImageUpdate용 `.zsync` 파일이 함께 제공됩니다. Wayland에서 펫 자동 이동을 사용하려면 XWayland가 필요하며, 사용자가 지정한 Electron 플랫폼 설정을 우선합니다.
