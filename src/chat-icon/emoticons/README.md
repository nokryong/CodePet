# CodePet character emoticons

- Canvas: square (1:1)
- Background: solid white
- Characters: `gemini`, `gpt`, `claude`
- Assets: 42 emoticons per character, 126 PNG files total
- Naming: normally the exact icon key, with Windows-invalid `?` sanitized according to `manifest.json`
- Personality direction:
  - Gemini: cheeky, teasing, smug
  - GPT: taciturn, blunt, restrained
  - Claude: elegant, proud, aloof

Each character interprets the same icon key with a different pose, expression, and framing.
