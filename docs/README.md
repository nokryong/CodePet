# CodePetMODnMOBILE 개발 문서

기준일: **2026-11-04 (Asia/Seoul)**

Windows PC용 CodePet 개선판과 **설치형 Android 앱**의 개발 기준이다.
이 문서에 있는 기능은 목표이며, 실제 구현 상태는 진행 문서에서 따로 관리한다.

| 문서 | 역할 |
|---|---|
| [ROADMAP.ko.md](ROADMAP.ko.md) | 합의한 범위, 단계, 선행 조건, 완료 기준 |
| [ARCHITECTURE.ko.md](ARCHITECTURE.ko.md) | PC 실행부, 에이전트, 브라우저, 모바일, 데이터 구조 |
| [STATUS.ko.md](STATUS.ko.md) | 완료 근거, 미검증 사항, 다음 작업 |
| [../AGENTS.md](../AGENTS.md) | 후속 개발자와 에이전트의 작업 지침 |

## 작업 시작 순서

1. `develop`을 기준으로 문서와 실제 코드를 읽는다.
2. 진행 문서에서 현재 단계와 미해결 기술 검증을 확인한다.
3. 해당 작업용 브랜치를 만들고 작게 구현·검증한다.
4. 변경과 근거를 진행 문서에 기록하고 `develop`에 통합한다.

현재 기반은 원본 `nokryong/CodePet` **v1.2.2**, 커밋
`ca3d5c1ce2d7f96e904deb68ac88c660b8251371`이다.
`main`은 원본 추적용이고, 이 계획과 개조판 개발 기준은 `develop`이다.
기존 원본 README의 다운로드 링크는 원본 배포를 가리키며 개조판 완성을 뜻하지 않는다.

## 첫 개발 이정표

**PC에서 Claude·Codex 각각에 메시지 → 필요한 도구 승인 → 결과 표시 →
모델/추론 변경 → 같은 대화 이어가기**를 먼저 검증한다.
Claude Chrome 연결과 Codex 브라우저 재사용 경로도 이때 확인한다.
그다음 같은 실행부에 Android 화면을 연결한다.

원본 코드와 변경 사항은 원본 라이선스·출처를 유지한다.
실제 계정·대화·로그인 정보는 개발 문서나 테스트 데이터에 포함하지 않는다.
